About the game

Crystal Cavern is an idle game that runs in a browser. There is nothing to download and nothing to sign up for, and it is free.

  • It makes no sound. No effects, no music. The author is deaf, and the aim was a design where the feedback holds up without relying on audio
  • You can choose how it reads. Four text sizes and five colour schemes, two of them maximum-contrast. It is fully playable from the keyboard
  • Five languages. English, 日本語, 简体中文, 한국어, Español
  • No server. Progress is stored only in your own browser

The reasoning behind all of this is set out in the making of.

Requirements

Any reasonably current browser. Tested on recent versions of Chrome, Safari, Firefox and Edge. The layout adapts to phones and desktops alike.

If your browser is set to block site data, or you are in private browsing, progress will not be saved. The game still plays; it simply starts over when you close it.

Liability

No responsibility is accepted for any loss arising from use of this site or the game.

Because progress lives in the browser, clearing browser data removes it. If a run matters to you, export a save code from the menu and keep it somewhere.
