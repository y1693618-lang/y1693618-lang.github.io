制作の話

Mac を持たずに、Windows と iPhone だけでアプリを出すまで

Mac も iPad も持っていない制作者が、Windows パソコンと iPhone だけで結晶洞窟を App Store に出すまでに使ったものと、その流れ。

iPhone のアプリを作るには、ふつう Mac が必要だと言われます。けれど私は、Mac も iPad も持っていません。手元にあるのは Windows のパソコンと iPhone だけです。それでも、結晶洞窟は App Store に並んでいます。

このページでは、Mac を使わずにアプリを出すまでに何を使い、どんな順番で進めたのかを書きます。なぜこのゲームを作ったのかは、作ったきっかけに書きました。

「Mac がないと無理」ではなかった

最初は、iPhone アプリは Mac がなければ作れないものだと思っていました。そこでAIに「Mac を持っていなくても iPhone のアプリは出せますか」と聞いてみました。返ってきた答えは、インターネット上の Mac を借りて、アプリを組み立ててくれるサービスがあるというものでした。

自分の手元に Mac がなくても、組み立てる作業だけをネットの向こうの Mac にやってもらえばいい、ということです。これを知って、iPhone アプリにできると分かりました。

作り始めてから、アプリが完成するまでは4日でした。

使ったもの

名前と使いみち費用

AIプログラムを書く、手順を教えてもらう、エラーの意味を聞く—
GitHubゲームとアプリのファイルをインターネット上に置いておく場所無料
Codemagicネット上の Mac を借りて、アプリを組み立てて Apple に送ってもらう個人の利用なら毎月500分まで無料
Apple Developer ProgramApp Store にアプリを出すための開発者登録年99米ドル

Apple Developer Program は、日本の App Store にある Apple Developer アプリから登録すると12,800円と表示されます。費用は2026年10月に調べたものです。変わることがあるので、登録するときにそれぞれの画面で確かめてください。

App Store に出すための情報の入力や審査の申し込みは、Apple の「App Store Connect」というページで行います。これはブラウザで開けるので、Windows のパソコンからそのまま使えました。

全体の流れ

  1. ゲームを作る。結晶洞窟は、もともとブラウザで遊べるゲームです。AIにプログラムを書いてもらい、Windows のブラウザで遊んで確かめながら作りました
  2. アプリの「外側」を作る。ゲームをそのまま包んで、iPhone のアプリとして動かすための部分です。ここもAIに書いてもらいました。中身のゲームは、ブラウザ版と同じものです
  3. ファイルを GitHub に置く。ブラウザからファイルをアップロードするだけです
  4. Apple の開発者登録をして、準備をする。Apple Developer Program に登録し、App Store Connect にアプリの枠と、Codemagic がアプリを Apple に送るための鍵を作ります
  5. Codemagic で組み立てる。ボタンを押すと、ネット上の Mac がアプリを組み立て、Apple に送ってくれます
  6. 自分の iPhone で確かめる。Apple の「TestFlight」というアプリを使うと、公開前のアプリを自分の iPhone に入れて試せます
  7. App Store Connect で入力して、審査に出す。アプリの説明文、スクリーンショット、プライバシーポリシーのページ、広告で使う情報の申告などを入力して、審査を申し込みます
  8. 審査に通ったら公開。

直したいところが出てきたら、ファイルを直して GitHub に置き直し、もう一度 Codemagic で組み立てます。ゲームの中身はブラウザ版とアプリ版で同じファイルなので、ゲームを直すときは、同じファイルをサイトとアプリの両方に置けばよく、アプリ側のプログラムを直す必要はありません。アプリ版は、組み立て直して審査に通ったあとに反映されます。

Mac がないぶん、工夫したところ

  • Xcode を自分では使わない。Mac でアプリを作るときに使う「Xcode」というソフトは、Windows では動きません。そこで、アプリの設計図を短い文字のファイルにしておき、組み立てるたびに、ネット上の Mac がその設計図からプロジェクトを作るようにしました
  • 動きの確認は実機で。Mac があれば、シミュレーター（画面の中で動く iPhone）で試せますが、それができません。そのかわり、TestFlight で自分の iPhone に入れて確かめました
  • 組み立ての回数に気をつける。Codemagic の無料の時間には、毎月の上限があります。直すところは一度にまとめてから組み立てると、無料の時間を節約できます

手続きでつまずかなかったのは、AIに聞きながら進めたから

振り返ってみると、手続きでつまずいたところは特にありませんでした。開発者登録も、Codemagic の設定も、App Store Connect の入力も、わからないところはその場でAIに聞きながら進めたので、止まらずにスムーズに進められました。

もしAIがなければ、どこかでつまずいたまま、先に進めなかったと思います。

審査のこと

結晶洞窟は、これまでの審査で一度もリジェクト（審査で落とされること）されたことがありません。最初の公開のあとも、17言語への対応（1.1）と、大きな数字の表示の改善（1.2）で新しい版を出しましたが、どちらもそのまま通りました。

公開されたとき

審査に通って App Store に並んだときは、ほっとしました。
